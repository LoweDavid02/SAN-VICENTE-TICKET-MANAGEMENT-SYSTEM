## Change Request Process

1. **Submit** → Change Request Form
2. **Evaluate** → Impact Analysis (PM + Tech Lead)
3. **Approve** → Change Control Board Decision
4. **Update** → WBS, Schedule, Budget
5. **Implement** → Execute Change
6. **Verify** → Confirm Implementation
7. **Close** → Document & Communicate
